# Toy Society Poverty Lab

Interactive classroom simulator exploring poverty thresholds, income transfers, equivalisation, and inequality in a toy society.

**Open the simulator:** https://rszarf-1.github.io/toy-society-poverty-lab/

**Matrix Detective (Session 5 game)** now has its own site: https://rszarf-1.github.io/matrix-detective/ (the old `matrix-detective/` path redirects there).

## Use

Open the link in a modern browser. No account or installation is required. You can also download `index.html` and open it locally.

The published `index.html` preserves the supplied Session 4 simulator. The population is illustrative, not an empirical dataset. The session plan and worksheet referenced in its footer are separate course materials and are not included here.

## Hosting and updates

GitHub Pages serves `index.html` from the root of the `main` branch. Commit changes to that file to update the live simulator.

All simulator logic is included in the HTML file. Google Fonts supplies optional web fonts, with system-font fallbacks.
